# links-tamara-rosa-acessorios

Landing page estilo Linktree para a marca Tamara Rosa Acessórios.

## Estrutura

- `index.html`: estrutura principal da página
- `styles.css`: identidade visual, responsividade e animações
- `script.js`: animações de entrada
- `assets/logo-tr.svg`: logo local utilizado no header

## Deploy

Como é uma página estática, basta publicar a pasta em serviços como Vercel, Netlify ou GitHub Pages.
